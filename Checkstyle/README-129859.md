# Quality Gate de Convenções de Nomes com Checkstyle — MemberName

**Aluno:** Daniel Silva — 129859

## Regra escolhida

- **Tipo de identificador:** atributos de instância (não estáticos).
- **Regra:** `MemberName`
- **Propriedade:** `format`
- **Expressão regular:** `^[a-z][a-zA-Z0-9]*$` (camelCase, começa por minúscula)
- **Severidade:** `error`
- **Action:** `dbelyaev/action-checkstyle@v3`
- **Ficheiros:** `checkstyle-129859.xml` e `.github/workflows/checkstyle-129859.yml`

Convenção baseada no Google Java Style Guide e nas convenções da Oracle: atributos em lowerCamelCase, por exemplo `totalTiros`.

## Teste realizado

Num ramo à parte foi introduzido propositadamente um atributo com nome fora da convenção, por exemplo `private int Total_Tiros;`. O Checkstyle indicou o ficheiro e a linha e o workflow falhou. Depois de renomear para `totalTiros`, o workflow passou.

## Limitações

O Checkstyle só verifica a forma do nome (a expressão regular). Não consegue saber se o nome é significativo (`x1` cumpre o padrão mas não descreve nada), nem se a abreviatura é compreensível ou se o nome representa corretamente o conceito do domínio.
