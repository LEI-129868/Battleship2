# Quality gate de nomes de métodos com Checkstyle

Aluno: Francisco Silva  
Número: LEI-129868

## Regra escolhida

- Tipo de identificador: métodos.
- Regra: MethodName.
- Propriedade: format.
- Expressão regular: ^[a-z][a-zA-Z0-9]*$
- Severidade: error.
- Âmbito: ficheiros Java na pasta src.
- Checkstyle: 14.4.0.
- Action: nikitasavinov/checkstyle-action@1.0.0.

Os nomes devem começar por uma letra minúscula e continuar apenas
com letras ou algarismos.

## Teste realizado

O método buildLegend de BoardWindow.java foi renomeado para
BuildLegend, atualizando também a sua chamada.
O Checkstyle identificou a violação de MethodName e indicou
o ficheiro e a linha.

O check checkstyle-129868 foi definido como obrigatório na proteção
de main e o merge ficou bloqueado enquanto estava vermelho.

Depois de repor o nome do método buildLegend, o quality gate voltou a passar.

## Limitações

A regra verifica o formato dos nomes dos métodos.
Um nome como abc pode respeitar a expressão regular e continuar
pouco significativo.
Esta configuração não verifica os nomes das classes, atributos
ou parâmetros.
